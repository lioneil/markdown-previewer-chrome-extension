Markdown Previewer

A Chrome extension that renders local Markdown files.

Add to Chrome View on GitHub

Setup

  1. Install the extension from the Chrome Web Store.
  2. Open its details page and turn on Allow access to file URLs.
    text 
    chrome://extensions/?id=nccgimhmfbjfiakcapgeofcfbpkpganp
  3. Open a .md or .markdown file in the browser.

Note

Works in Chrome and Brave.

Features

Keyboard shortcuts

ShortcutAction
Alt+Shift+TCycle theme
Ctrl+Shift+KToggle sidebar
Ctrl+Shift+FSearch outline
Ctrl+Shift+WToggle wide mode (macOS only)
Ctrl+Shift+GToggle serif font
Ctrl+Shift+=Increase font size
Ctrl+Shift+-Decrease font size

Privacy

The extension makes no network requests and does not upload your files. Settings are stored in chrome.storage.sync.
